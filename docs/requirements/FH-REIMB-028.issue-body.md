# Issue body — Open invoice PDF directly from reimbursements

## Product request
When FamilyHub has already collected an invoice PDF and stored it in Google Drive, the reimbursement card should provide direct access to that invoice from FamilyHub so the user does not need to search Drive manually.

## Requirement
Track as **FH-REIMB-028**.

## Acceptance criteria
- A reimbursement with an available invoice PDF exposes an obvious open/view action.
- The action opens the correct invoice for that expense.
- The user can reach the invoice without manually searching Google Drive.
- No misleading active action is shown when no PDF exists.
- Existing reimbursement matching, workflow, confidence, and source-evidence behavior is preserved.
- The implementation remains mobile/PWA friendly.

## Scope
Documentation only for now. Do not implement in this phase.
